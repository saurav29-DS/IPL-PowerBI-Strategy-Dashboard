# IPL Strategy Analytics Dashboard | Power BI

An interactive Power BI dashboard analysing IPL match strategy, venue trends, player performance, and high-impact batter–bowler matchups.

## Dashboard Pages

### 1. Match Strategy Analytics
- Toss decision win rate: fielding first vs batting first
- Venues with the strongest chasing advantage
- IPL match distribution across host cities
- IPL final-winning strategies: defending totals vs chasing targets
- Key strategic insights from 19 IPL seasons

### 2. Player Performance Analytics
- Best death-over batters by strike rate
- Best death-over bowlers by economy rate
- Batter–bowler head-to-head performance
- Bowler–batter wicket-taking dominance
- Most Player of the Match awards
- All-rounder impact based on runs and wickets

## Key Insights
- Teams choosing to field after winning the toss achieved a higher win rate than teams choosing to bat.
- Sawai Mansingh Stadium showed the strongest advantage for chasing teams.
- IPL finals were closely balanced between successful chases and defended totals.
- Death-over analysis identifies specialist finishers and economical bowlers.
- Head-to-head analysis highlights matchups where batters score quickly or bowlers take key wickets.

## Tools Used
- Power BI Desktop
- Power Query for data cleaning and transformation
- DAX for measures and calculations
- MySQL for the supporting SQL analysis
- IPL match-level and ball-by-ball dataset
